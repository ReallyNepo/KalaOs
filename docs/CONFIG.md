# KalaOS Configuration Reference

## kalaos.conf - Complete Reference

### Kernel & Boot

| Variable | Default | Description |
|----------|---------|-------------|
| `KERNEL_VARIANT` | `cachyos-bore` | Kernel variant: `cachyos-bore`, `cachyos-eevdf`, `linux-zen` |
| `KERNEL_CMDLINE` | `nvme.noacpi=1 mitigations=off transparent_hugepage=always nowatchdog` | Kernel command line parameters |
| `BOOTLOADER` | `systemd-boot` | Bootloader: `systemd-boot`, `grub`, `refind` |

### Hardware

| Variable | Default | Description |
|----------|---------|-------------|
| `GPU_VENDOR` | `auto` | GPU vendor: `auto`, `nvidia`, `amd`, `intel`, `hybrid` |
| `NVIDIA_DRIVER` | `auto` | NVIDIA driver: `auto`, `nvidia-open-dkms`, `nvidia-dkms`, `nvidia-lts-dkms` |
| `ENABLE_VULKAN_LAYERS` | `true` | Enable Vulkan layers (MangoHud, vkBasalt, etc.) |

### Gaming Stack

| Variable | Default | Description |
|----------|---------|-------------|
| `ENABLE_GAMING` | `true` | Enable gaming stack |
| `GAMESCOPE_SESSION` | `true` | Enable gamescope session |
| `PROTON_VARIANT` | `GE-Proton` | Proton variant: `GE-Proton`, `proton-experimental`, `proton-hotfix` |
| `STEAM_DECK_UI` | `false` | Enable Steam Deck UI mode |

### Desktop (Hyprland)

| Variable | Default | Description |
|----------|---------|-------------|
| `HYPRLAND_ANIMATIONS` | `true` | Enable animations |
| `HYPRLAND_BLUR` | `true` | Enable blur |
| `HYPRLAND_GAPS` | `true` | Enable gaps |
| `HYPRLAND_ROUNDING` | `8` | Window rounding radius |
| `WORKSPACE_COUNT` | `10` | Number of workspaces |

### Terminal (Ghostty)

| Variable | Default | Description |
|----------|---------|-------------|

## Environment Variables (set by install)

| Variable | Description |
|----------|-------------|
| `PROTON_HIDE_NVIDIA_GPUS=0` | Show NVIDIA GPUs to Proton |
| `PROTON_ENABLE_NVAPI=1` | Enable NVAPI for DLSS |
| `DXVK_ASYNC=1` | Enable DXVK async |
| `VKD3D_CONFIG=dxr11,multi_queue` | VKD3D config |
| `RADV_PERFTEST=aco,ngg,nggc` | AMD RADV perf |
| `MESA_SHADER_CACHE_MAX_SIZE=16G` | Shader cache size |
